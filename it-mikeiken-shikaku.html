資格選びで一番大事なのは、 どの仕事を目指すか です。

更新：2026年9月30日

結論： 全員が同じ資格を 取る必要はありません。

目安として、 IT全体の基礎 → ITパスポート
技術基礎を広く → 基本情報技術者
ネットワーク → CCNA

AWS・クラウド → AWS Cloud Practitioner と考えると整理しやすいです。

ただし、 資格取得を待って 半年間まったく応募しない のが必ず正解というわけでもありません。

資格は 「内定を取る魔法」ではない

資格は、 未経験者にとって 勉強する範囲を決めたり、 基礎知識を学んだことを 示したりする材料になります。

一方で、 資格を取っただけで 実務経験者と同じスキルになるわけではありません。

資格の目的を 「資格を取ること」にしない。

希望職種に必要な知識を学ぶために 資格を利用する。

IT未経験者が 検討しやすい資格5つ

資格 主な分野 向きやすい職種 特徴
ITパスポート IT、 セキュリティ、 経営、 マネジメント ITサポート、 社内IT、 職種未定 IT全体を広く学ぶ 国家試験
基本情報技術者 IT全般、 アルゴリズム、 セキュリティ等 開発、 エンジニア全般 ITパスポートより 技術寄り
CCNA ネットワーク、 IP、 セキュリティ、 自動化 ネットワーク、 インフラ Ciscoの ネットワーク資格

AWS Cloud Practitioner AWS、 クラウド基礎 クラウド、 IT全般 AWS認定の Foundational

「おすすめ度」は 人によって変わるため、 目指す仕事から逆算して選びます。

30秒｜ 自分ならどの資格？

今の状態に近いものを 選んでください。

診断結果は目安です。 実際には応募したい求人の 必須・歓迎条件も確認してください。

1

ITパスポート

国家試験 IT基礎 初心者向け

ITパスポートは、 情報処理技術者試験の一つである 国家試験です。

IT技術だけでなく、 企業活動、 経営戦略、 マネジメント、 セキュリティなどを 幅広く扱います。

方式 CBT
試験時間 120分
出題数 100問
受験手数料 7,500円
候補になりやすい人
  • IT用語がほとんど分からない
  • まだIT職を決めていない
  • 社内IT・サポート系を考えている
  • 広く基礎から学びたい
注意

ネットワークエンジニア志望なのに ITパスポートだけを何か月も勉強するより、 基礎を理解したら ネットワーク学習へ進む方が 目的に合う場合があります。

2

基本情報技術者試験

国家試験 技術基礎 アルゴリズム

基本情報技術者試験は、 ITパスポートよりも 技術者向けの内容を含む国家試験です。

科目Bでは 情報セキュリティと アルゴリズム・プログラミング的思考を 中心に問います。

科目A 90分・60問
科目B 100分・20問
方式 CBT
受験手数料 7,500円
候補になりやすい人
  • 開発職を考えている
  • IT技術全体の基礎を深めたい
  • アルゴリズムも学びたい
  • ITパスポートより一段深く学びたい

2026年は試験システム更新に伴い、 年末以降に試験実施休止予定があります。 受験時にはIPAの最新日程を確認してください。

3

CCNA

Cisco ネットワーク インフラ

CCNAは Ciscoのネットワーク資格です。

現行の 200-301 CCNA v1.1 では、 ネットワークの基礎、 ネットワークアクセス、 IPコネクティビティ、 IPサービス、 セキュリティ、 自動化・プログラマビリティ等を扱います。

試験 200-301
試験時間 120分
主分野 ネットワーク
前提資格 なし
候補になりやすい人
  • ネットワークエンジニア志望
  • インフラエンジニア志望
  • IP・ルーティング等を体系的に学びたい
資格だけでなく 実際にネットワークを触る。

学習時に Packet Tracer等を使って 設定を試すと、 単語の暗記だけより 仕事内容を理解しやすくなります。

4

LinuCレベル1

Linux サーバー インフラ

LinuCレベル1は、 Linuxシステムの 基本操作・構築・運用管理に関する スキルを確認する認定です。

2026年9月時点では Version 10.0 が公開されています。

必要試験 101＋102
問題数 各 約60問
試験時間 各90分
費用 各16,500円

レベル1認定には 101試験・102試験の 両方への合格が必要です。

候補になりやすい人
  • Linuxサーバーを学びたい
  • インフラエンジニア志望
  • 将来クラウドも触りたい
  • コマンド操作を体系的に学びたい
Linuxは 試験問題だけでなく 実際に触るのがおすすめ。

仮想環境などを使い、 cd、 ls、 grep、 chmod等の 基本操作から試してみましょう。

5

AWS Certified Cloud Practitioner

AWS クラウド Foundational

AWS Certified Cloud Practitionerは、 AWSクラウド、 主要サービス、 クラウド用語等の 基礎理解を確認する Foundationalレベルの認定です。

AWS自身も、 IT・クラウド経験がない人にとって 認定ジャーニーの 出発点として案内しています。

試験コード CLF-C02
試験時間 90分
問題数 65問
レベル Foundational
候補になりやすい人
  • AWSに興味がある
  • クラウドの全体像を知りたい
  • インフラ・クラウド志望
Cloud Practitionerだけで クラウドエンジニア完成ではない。

Linux、 ネットワーク、 AWSの実操作なども 合わせて学ぶと 実務イメージを作りやすくなります。

よくある質問

完全未経験なら ITパスポートから？

IT用語がほとんど分からない場合は 基礎を広く学ぶ入口になります。

ただし、 ネットワーク等 目標職種が明確なら その分野の基礎学習へ 早めに進む方法もあります。

資格なしでも IT転職できる？

資格必須ではない求人もあります。 求人条件を確認し、 資格取得だけでなく 現在の学習や前職経験も整理してください。

CCNAとLinuCならどっち？

ネットワーク中心ならCCNA、 Linuxサーバー中心ならLinuCが 分かりやすい選択肢です。

インフラでは 両方の知識が関係する場合もあります。

AWS Cloud Practitionerだけで クラウドへ転職できる？

資格だけで 実務スキルが保証されるわけではありません。

Linux、 ネットワーク、 AWSの実操作も 並行して学ぶとよいでしょう。

基本情報は難しい？

ITパスポートより 技術寄りの範囲を含み、 科目Bでは アルゴリズム・プログラミング的思考も扱います。

完全初心者なら、 基礎用語を理解してから 進む方法もあります。

資格は何個取ればいい？

数に正解はありません。 希望職種に直接関係する資格を 一つ選び、 求人応募や実際の操作を 並行する方が目的を明確にしやすいです。
